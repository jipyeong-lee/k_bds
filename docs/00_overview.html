0. 요약 · 최종 결과

Stage-1 과 Stage-2 를 끝냈다. Stage-2 결과로 전문가 3종과 통합 모델(ta_w07)을 만들었다. Stage-3 는 준비까지 했다.

핵심 결과 5개
  1. Stage-1 은 RL 의 전제다(2,048 토큰 조건). 콜드스타트 없이 RL 을 하면 holdout 0.18, 콜드스타트 + RL 은 0.38 이다(2×2 ablation). 단 8,192 토큰에서는 기본 모델 holdout(50.45%)이 SFT(42.67%)보다 높다. 기본 모델은 응답이 약 9배 길고 형식 준수율이 낮다(1.6).
  2. GRPO 변형 5종 중 dr_grpo 와 GDPO 가 이겼다. 기본 GRPO 의 정체(plateau)를 넘었다.
  3. 도메인 전문가 3종 모두 글로벌 의료 벤치에서 SFT 를 넘었다. 최고는 deepvision 57.52%(SFT 46.77%, +10.75pp).
  4. 형식 붕괴 전에 학습↔롤아웃 불일치가 먼저 커진다. TIS 보정은 붕괴를 늦추지만 막지 못한다.
  5. 전문가 3종은 추가 학습 없이 합쳐진다. task vector 가 거의 직교한다. 단순 가중 합산(ta_w07)이 세 도메인을 95~108% 보존했다. K-BDS 전체셋 본평가에서 holdout 63.32%(SFT 42.67%), 글로벌 56.22%(SFT 46.77%)다.

1. Stage-1 · 콜드스타트 SFT

1.1 목적

  • base 모델은 추론을 길게 쓴다(3.5~4.6K 토큰). 출력이 잘려 답에 닿지 못한다(파일럿 77% 잘림).
  • 답이 없으면 보상이 0 이다. 보상이 0 이면 RL 은 학습하지 못한다.
  • 콜드스타트 SFT 는 짧은 추론과 <think>/<answer> 형식을 가르친다.

  • pmcvqa 의 +1.5pp 는 n=400 노이즈 범위다. pass@8 은 83.0% 다. 모델은 답을 알지만 RL 이 그 능력을 끌어내지 못했다.
  • deepvision 전문가의 pmcvqa holdout 은 56.75% 로 init 과 같다. 다른 도메인 망각은 없다.
  • 탈락: deepvision 2700(holdout 55.6%, 형식 0.765), mmk12 400(58.25%).
주의. deepvision 의 SFT 값은 측정이 2개다. 9월 측정은 35.19%, 10월 재측정(job 82983)은 35.8% 다. 이 문서와 결과보고서는 같은 시기 측정쌍(35.19 → 67.39)을 쓴다.

3. Stage-3 · 의료 개방형 RL (RaR) 준비

보상 함수, 심판 모델, 학습 배선을 준비했다. 본 학습은 2차 과제로 넘긴다.

3.1 보상: 루브릭 기반 보상(Rubric-as-a-Reward)

항목유형(가중치)판정 기준
c1 정답 일치필수(5)<answer> 가 참조 답과 의미가 같다(동의어·단위 환산 허용)
c2 시각 근거중요(3)<think> 가 이미지와 모순 없는 관찰을 쓴다
c3 수치·단위중요(3)측정형 문제만. 참조 답의 ±15% 이내
c4 환각 없음함정(4)이미지에 없는 소견을 주장하지 않는다
  • 보상 = Σ wⱼ·cⱼ / Σ wⱼ (0~1). 형식을 어기면 심판을 부르지 않고 0 을 준다.
  • 문제마다 루브릭을 만드는 방식보다 고정 루브릭이 환각 변별에서 나았다(+0.338 대 +0.021).
  • 코드: configs/medical_reward.py. 단위 시험 29/29 통과.
