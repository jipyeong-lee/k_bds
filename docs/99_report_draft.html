연구 요약서

K-BDS 분석 인프라 활용지원 프로그램(2026년 1차, Track III)
연구 제목
(Title)		의료 및 바이오 도메인 특화 멀티 모달 교차 추론 인공지능 모델 개발
(Development of a Multimodal Cross-Domain Reasoning Model Specialized for Medical and Bio Domains)
연구 책임자이현훈
책임자 소속서울대학교병원 · 융합의학과
연구 목적
  • 멀티모달 대형 언어 모델(Qwen3.5-9B)에 강화학습을 적용함. 목표는 시각 인지 능력과 단계적 추론 능력을 높이는 것임.
  • 범용 멀티모달 추론 데이터(DeepVision-103K, MMK12)와 의료 멀티모달 데이터(PMC-VQA)로 학습함.
  • 의료 글로벌 벤치마크(이하 글로벌 벤치마크)에서 SFT(지도 미세조정) 모델 대비 성능 향상을 정량으로 입증하는 것이 목표임. 글로벌 벤치마크는 학습 데이터와 출처가 다른 공개 평가 문항임. 구성은 MedXpertQA-MM(의료 전문 시험형 멀티모달 문항)과 MMMU-H&M(대학 수준 문항 중 보건·의학 분야)임.
  • K-BDS 8gpu 노드(A100 80GB × 8)에서 재현 가능한 강화학습 파이프라인(데이터 전처리 → SFT → 강화학습 → 전문가 병합 → 평가)을 구축함. 이 파이프라인을 K-BDS 마켓플레이스에 등록함.
시스템
활용 효과
  • 9B 모델 강화학습 실행: GRPO 는 한 문항에 응답 여러 개를 만들어 서로 비교하며 학습하는 강화학습 알고리즘임. GRPO 는 정책 모델(학습하는 모델)과 vLLM 롤아웃 엔진(학습 중 응답을 만드는 엔진)을 동시에 메모리에 올림. A100 40GB 단일 GPU 에서는 메모리 부족(OOM)으로 학습할 수 없음(실측). K-BDS 8gpu 노드(A100 80GB × 8)에서 수학·의료 전문가 학습, 혼합 데이터 학습, GRPO 변형 5종 비교를 수행함.
  • 1 epoch(학습 데이터 전체를 한 번 학습) 장기 학습 완주: 8gpu 노드에서 GRPO 학습 1 단계(step)는 약 213초임(실측). 학습을 여러 작업(job)으로 나누어 실행함. 각 작업은 앞 작업의 체크포인트(학습 중 저장한 모델)에서 재개함. 이렇게 의료 전문가(pmcvqa)의 1 epoch(4,896 step)을 완주함.
  • 대용량 데이터 상주: 원본·전처리 데이터 약 305GB 를 K-BDS 스토리지에 둠. 이 데이터로 전문가 학습과 체크포인트별 평가를 반복함.
  • 사용 자원: 총 5,070.1 노드시간을 사용함(할당 5,000 노드시간 대비 101.4%).
  • 비용 절감(지원이 없었을 때와 비교): 1 노드시간은 A100 1장의 1시간 사용임(공고문 정의). 8gpu 노드 1시간은 8 노드시간임. 그러므로 5,070 노드시간은 A100 약 5,070 GPU시간임. 상용 클라우드 A100 80GB 단가는 GPU시간당 약 2~5 달러임. 이 단가로 계산한 상용 클라우드 환산 비용은 약 1.0~2.5만 달러임(추정). 원화로는 약 1,400~3,500만 원임(1달러 = 1,400원으로 가정).
연구 내용
및 결과
1. 데이터 구축 및 등록
  • 범용 멀티모달 추론 데이터 DeepVision-103K(10.3만 건, 10GB)를 K-BDS 에 등록함(등록번호 10.23220/KBDSC_20260306133407_2096).
  • 의료 멀티모달 데이터 medix-rl-data(5.1만 건, 24GB)를 K-BDS 에 등록함(등록번호 10.23220/KBDSC_20260306133400_2097). 이 데이터를 의료 개방형(서술형 답) 강화학습(7절)의 보상 함수 검증에 사용함.
  • 공개 데이터셋 MMK12(수학 추론, 1.5만 건)와 PMC-VQA(의료 VQA: 의료 영상 질의응답, 사용분 2.0만 건)를 함께 사용함(K-BDS 미등록).
  • 강화학습 데이터를 3개 도메인으로 나눔: 시각 추론(deepvision) 40,000건, 수학 추론(mmk12) 15,204건, 의료 VQA(pmcvqa) 19,583건.
  • 평가용 holdout(학습에 쓰지 않은 평가 문항) 1,772건을 분리함. 이미지 해시로 학습 데이터와의 중복을 제거함.
2. 콜드스타트 SFT
  • 강화학습 전에 모델이 <think>(추론)·<answer>(답) 형식으로 답하도록 먼저 학습함(콜드스타트 SFT). 이 결과물을 SFT 모델이라 부름.
  • 범용·의료 혼합 데이터 9,889건으로 SFT 데이터를 다시 구성함. 형식 준수율은 응답이 <think>·<answer> 형식을 지킨 비율임. 이 데이터로 학습한 모델의 형식 준수율은 이전 버전(v2)의 0.185 에서 0.909 로 오름(최대 출력 2,048 토큰).
  • SFT 필요성 검증(ablation: 구성 요소를 하나씩 빼고 비교하는 실험): 이 비교에는 이전 버전 SFT(v2)를 씀. 평가 조건은 DeepVision holdout 중 층화 추출한 200문항, 최대 출력 2,048 토큰임.
  • 기본 모델(추가 학습 전의 Qwen3.5-9B)에서 바로 강화학습하면 holdout 정확도가 0.15 에서 0.18 로 오름. SFT 후 강화학습하면 0.22 에서 0.38 로 오름. 그러므로 이 조건에서 SFT 가 없으면 강화학습 효과가 작음(+0.03 대 +0.16).
3. 강화학습 방법론 비교 및 학습 구조 결정
  • 목적: 기준 GRPO 의 학습 정확도 정체를 넘는 알고리즘을 고름. 기준 GRPO 는 학습 정확도 0.50 에서 정체함. 원인은 학습 신호가 0 인 그룹의 증가임(비율 0.24 → 0.33). 이 그룹은 한 문항에 만든 응답이 모두 맞거나 모두 틀린 묶음임.
  • 설정: 시작 모델은 이전 버전 SFT(v2)임. 데이터는 DeepVision 학습 분할임. 각 변형을 600 step 학습함. 평가는 위와 같은 DeepVision holdout 200문항, 최대 출력 2,048 토큰임.

  • 혼합 학습 실험: 세 도메인 데이터(74,787건)를 한 모델에 섞어 학습함. step 850 에서 도메인 holdout(1,772문항) 정확도가 SFT 모델보다 8.18pp(퍼센트포인트) 높음. 이 차이는 통계적으로 유의함(p<0.0001). 약 900 step 에서 출력 형식이 무너짐(형식 붕괴). 의료 VQA 정확도는 평가 시점 6곳 모두에서 유의하게 오르지 않음.
  • 계획 변경: step 850 까지 혼합 학습은 각 도메인 데이터를 0.09 epoch 만 학습함. 도메인별로 학습하면 같은 step 에서 각 도메인 데이터를 1.9~4.9배 더 학습함. 그래서 도메인별로 전문가를 따로 학습한 뒤 병합하는 구조로 바꿈.
4. 도메인 전문가 강화학습
  • 강화학습은 정답을 자동으로 확인할 수 있는 보상을 씀(RLVR: 검증 가능한 보상 강화학습).
  • 3절에서 정한 알고리즘(Dr.GRPO 손실 + GDPO 보상 정규화)과 학습 구조(도메인별 전문가)를 씀.
  • 학습은 LoRA 로 함. LoRA 는 원 가중치를 고정하고 작은 보조 행렬만 학습하는 방법임. 보조 행렬 크기(r)는 16 임.
  • 보상은 정확도·형식·길이 점수의 합임.

5. 학습 붕괴 원인 분석
  • 목적: 장기 학습에서 생기는 형식 붕괴의 원인을 찾음.
  • 형식 붕괴는 mmk12 약 450 step, deepvision 3,428 step 에서 생김.
  • 붕괴한 응답의 96% 이상은 추론 종료 표시(</think>)를 출력하기 전에 끊김.
  • 붕괴 전에 학습 엔진과 롤아웃 엔진(vLLM)이 같은 응답에 매긴 확률의 차이가 커짐. 이 차이(로그 퍼플렉서티 차이)는 mmk12 학습 1~350 step 동안 0.04 에서 0.82 로 커짐.
  • 토큰 단위 중요도 보정(TIS, Truncated Importance Sampling)은 두 엔진의 확률 비율이 큰 토큰에서 그 비율을 상한값(2.0)으로 자르는 방법임. 통제 실험(같은 체크포인트에서 TIS 유무만 바꿈)에서 TIS 는 붕괴를 약 20 step 늦춤. 그러나 붕괴를 막지 못함.
  • 이 결과로 전문가 선택 기준을 정함. 형식 준수율이 떨어지기 전의 체크포인트 중 holdout 정확도가 가장 높은 것을 고름.
6. 전문가 병합
  • 세 전문가의 가중치 변화량(task vector)은 서로 거의 직교함(코사인 유사도 +0.01 ~ +0.11). 코사인 유사도는 1 이면 같은 방향, 0 이면 직교임. 직교하면 더해도 서로 간섭이 작을 것으로 예측함. 그래서 추가 학습 없이 가중치를 더하는 병합을 시도함.
  • 병합 도구 mergekit 으로 병합 후보 11종을 만듦(Task Arithmetic, TIES, DARE, DELLA, Breadcrumbs, Model Stock, RAM 등의 방법과 설정 조합).
  • DELLA 1종은 도구 오류로 제외함. 나머지 10종을 축소 평가 문항(holdout 600·글로벌 벤치마크 600)으로 비교함.
  • 상위 2종(Task Arithmetic, Breadcrumbs)을 K-BDS 에서 전체 평가 문항으로 측정함. 두 후보의 차이는 통계적으로 유의하지 않음. 검정은 같은 문항에서 두 모델의 정답 여부를 짝지어 비교하는 McNemar 검정을 씀. 결과는 holdout p=0.72, 글로벌 벤치마크 p=0.25 임(두 값 모두 0.05 보다 큼).
  • 그러므로 더 단순한 Task Arithmetic(λ=0.7)으로 병합한 모델을 최종 통합 모델(세 전문가를 합친 모델)로 정함. Task Arithmetic 은 각 전문가의 가중치 변화량에 같은 계수 λ 를 곱해 SFT 모델에 더하는 방법임.

  • 도메인별 holdout(기본 모델 → 통합 모델)은 시각 추론 44.86% → 64.20%, 수학 추론 60.0% → 65.50%, 의료 VQA 54.5% → 59.00% 임.
  • 기본 모델의 holdout 점수는 SFT 모델보다 높음(50.45% 대 42.67%). 기본 모델은 형식 준수율이 0.638 이고, 평균 응답 길이가 SFT 모델의 약 6배임. SFT 는 강화학습 전에 응답 형식과 길이를 맞추는 단계임.

7. 의료 개방형 강화학습(복합 보상) 준비
  • 복합 보상 함수를 구현함. 이 함수는 정확도·의미 일치·형식 점수를 합침.
  • LLM 심판(LLM-as-a-judge)의 채점 기준표(루브릭)를 구현함. 단위 테스트 29개를 모두 통과함.
  • 심판 모델 후보를 비교하여 1개를 선정함.
  • 복합 보상을 쓰는 짧은 시험 학습(스모크 시험)을 끝까지 실행함.
  • K-BDS 계산 노드는 외부망이 없어 외부 심판 API 를 호출할 수 없음. 그래서 본 학습(medix-rl-data, 통합 모델에서 시작)은 후속 과제에서 수행할 예정임.
