연구 요약서

K-BDS 분석 인프라 활용지원 프로그램(2026년 1차, Track III)
연구 제목
(Title)		의료 및 바이오 도메인 특화 멀티 모달 교차 추론 인공지능 모델 개발
(Development of a Multimodal Cross-Domain Reasoning Model Specialized for Medical and Bio Domains)
연구 책임자이현훈
책임자 소속서울대학교병원 · 융합의학교수
연구 목적
  • 멀티모달 대형 언어 모델(Qwen3.5-9B)에 강화학습을 적용함. 목표는 시각 인지와 단계적 추론 능력의 향상임.
  • 범용 멀티모달 추론 데이터(DeepVision-103K, MMK12)와 의료 멀티모달 데이터(PMC-VQA)로 학습함.
  • 의료 글로벌 벤치마크(MedXpertQA-MM, MMMU-H&M)에서 SFT(지도 미세조정) 모델 대비 성능 향상을 정량으로 입증함.
  • K-BDS 8gpu(A100 80GB) 노드에서 재현 가능한 강화학습 파이프라인(데이터 전처리 → SFT → 강화학습 → 전문가 병합 → 평가)을 구축함. 이 파이프라인을 K-BDS 마켓플레이스에 기탁함.
시스템
활용 효과
  • 9B 모델 강화학습의 실행: GRPO 는 한 문항에 응답 여러 개를 만들어 서로 비교하며 학습하는 강화학습 알고리즘임. GRPO 는 정책 모델(학습 상태 포함)과 vLLM 롤아웃 엔진(학습 중 응답을 만드는 엔진)을 동시에 메모리에 올림. A100 40GB 단일 GPU 에서는 메모리 부족(OOM)으로 학습할 수 없음(실측). K-BDS 8gpu(A100 80GB × 8) 노드에서 9B 모델의 GRPO 학습을 수행함. 수행한 학습은 수학·의료 도메인 전문가, 혼합 데이터 학습, GRPO 변형 5종 비교임.
  • 1 epoch(학습 데이터 전체를 한 번 학습) 장기 학습 완주: 8gpu 노드에서 GRPO 학습 1 단계(step)는 약 213초임(실측). 체크포인트 재개를 이어 붙여 의료 전문가(pmcvqa)의 1 epoch(4,896 step)을 완주함.
  • 대용량 데이터 상주: 원본·전처리 데이터 약 305GB 를 K-BDS 스토리지에 둠. 이 데이터로 전문가 학습과 체크포인트별 평가를 반복함. 데이터를 외부로 옮기지 않고 재사용함.
  • 사용 자원: 총 5,070.1 노드시간을 사용함(할당 5,000 노드시간 대비 101.4%).
  • 비용 절감(지원이 없었을 때와 비교): 1 노드시간은 A100 1장의 1시간 사용임. 그러므로 5,070 노드시간은 A100 약 5,070 GPU시간임. 상용 클라우드 A100 80GB 단가는 GPU시간당 약 2~5 달러임. 이 단가로 환산한 절감액은 약 1.0~2.5만 달러(약 1,400~3,500만 원)임(추정, 1달러 = 1,400원).
연구 내용
및 결과
1. 데이터 구축 및 등록
  • 범용 멀티모달 추론 데이터 DeepVision-103K(10.3만 건, 10GB)를 K-BDS 에 등록함(등록번호 10.23220/KBDSC_20260306133407_2096).
  • 의료 멀티모달 데이터 medix-rl-data(5.1만 건, 24GB)를 K-BDS 에 등록함(등록번호 10.23220/KBDSC_20260306133400_2097). 이 데이터는 의료 개방형 강화학습(7절)의 보상 함수 검증에 사용함.
  • 공개 데이터셋 MMK12(수학 추론, 1.5만 건)와 PMC-VQA(의료 VQA, 2.0만 건)를 함께 활용함(K-BDS 미등록).
  • 강화학습 데이터를 3개 도메인으로 나눔: 시각 추론(deepvision) 40,000건, 수학 추론(mmk12) 15,204건, 의료 VQA(pmcvqa) 19,583건.
  • 평가용 holdout(학습에 쓰지 않은 평가 문항) 1,772건을 분리함. 이미지 해시로 학습 데이터와의 중복을 제거함.
2. 콜드스타트 SFT
  • 콜드스타트 SFT(이하 SFT) 모델은 <think>(추론)·<answer>(답) 형식으로 답하도록 학습한 모델임.
  • 일반·의료 혼합 데이터 9,889건으로 SFT 데이터를 다시 구성함. 이 데이터로 형식 준수율이 이전 버전의 0.185 에서 0.909 로 오름.
  • 필요성 검증(구성 요소를 하나씩 빼는 비교 실험, ablation): 이 비교는 이전 버전 SFT(v2)로 함. 평가 조건은 DeepVision holdout 200문항, 최대 출력 2,048 토큰임.
  • SFT 없이 강화학습하면 holdout 정확도가 0.15 에서 0.18 로 오름. SFT 후 강화학습하면 0.22 에서 0.38 로 오름. 그러므로 이 조건에서 SFT 는 강화학습의 전제 조건임.
3. 강화학습 방법론 비교
  • 목적: 기본 GRPO 의 정체를 넘는 알고리즘을 고름. 기본 GRPO 는 학습 정확도 0.50 에서 정체함. 원인은 학습 신호가 0 인 그룹(응답이 모두 맞거나 모두 틀림)의 증가임(비율 0.24 → 0.33).
  • 설정: 시작 모델은 이전 버전 SFT(v2)임. 데이터는 DeepVision 학습 분할임. 각 변형을 600 step 학습함. 평가는 DeepVision holdout 200문항, 최대 출력 2,048 토큰임.

  • 혼합 학습 실험: 세 도메인 데이터(74,787건)를 한 모델에 섞어 학습함. step 850 에서 holdout 정확도가 SFT 대비 8.18pp(퍼센트포인트) 오름(p<0.0001). 약 900 step 에서 출력 형식이 무너짐(형식 붕괴). 의료 VQA 는 측정한 6개 지점에서 모두 개선이 없었음.
  • 계획 변경: 혼합 학습은 각 도메인 데이터를 0.09 epoch 만 학습함. 도메인별로 학습하면 같은 step 에서 각 도메인 데이터를 1.7~4.9배 더 학습함. 그래서 도메인별로 전문가를 따로 학습한 뒤 병합하는 구조(DeepSeek-V4 방식)로 바꿈.
4. 도메인 전문가 강화학습
  • 강화학습 방식은 검증 가능한 보상을 쓰는 강화학습(RLVR)임. 알고리즘은 GRPO 계열임.
  • 3절에서 정한 알고리즘(Dr.GRPO 손실 + GDPO 보상 정규화)과 학습 구조(도메인별 전문가)를 씀.
  • 학습은 LoRA(모델 가중치의 일부만 학습하는 방법, r=16)로 함. 보상은 정확도·형식·길이 점수의 합임.

5. 학습 붕괴 원인 분석
  • 학습을 오래 하면 형식 붕괴가 생김(mmk12 약 450 step, deepvision 3,428 step).
  • 붕괴한 응답의 96% 이상은 추론 종료 태그 전에 끝남.
  • 붕괴 전에 학습 엔진과 롤아웃 엔진(vLLM)의 확률 차이가 먼저 커짐. 이 차이(로그 퍼플렉서티 차이)는 0.04 에서 0.82 로 커짐.
  • 통제 실험(같은 체크포인트에서 보정 유무만 바꿈): 토큰 단위 중요도 보정(TIS)은 붕괴를 약 20 step 늦춤. TIS 는 붕괴 폭을 줄이지만 붕괴를 막지 못함.
  • 이 결과로 붕괴 직전 체크포인트를 전문가로 고르는 기준을 정함.
6. 전문가 병합
  • 세 전문가의 가중치 변화량(task vector)은 서로 거의 직교함(코사인 유사도 +0.01 ~ +0.11). 그러므로 추가 학습 없이 가중치를 더해 병합할 수 있음.
  • 병합 도구 mergekit 으로 병합 후보 11종을 설계함(Task Arithmetic, TIES, DARE, DELLA, Breadcrumbs, Model Stock, RAM 등).
  • 후보 10종을 비교함. DELLA 1종은 도구 오류로 제외함.
  • 상위 2종(Task Arithmetic, Breadcrumbs)을 K-BDS 에서 전체 평가셋으로 측정함. 두 후보의 차이는 통계적으로 유의하지 않음(짝지은 검정 p=0.72, 0.25).
  • 그러므로 더 단순한 Task Arithmetic(λ=0.7)을 최종 통합 모델로 정함. Task Arithmetic 은 각 전문가의 가중치 변화량에 같은 계수 λ 를 곱해 SFT 모델에 더하는 방법임.

7. 의료 개방형 강화학습(복합 보상) 준비
  • 복합 보상 함수를 구현함. 이 함수는 정확도·의미 일치·형식 점수를 합침.
  • LLM 심판(LLM-as-a-judge) 루브릭을 구현함. 단위 시험 29개를 모두 통과함.
  • 심판 모델 후보를 비교하여 1개를 선정함. 짧은 시험 학습(스모크 시험)을 통과함.
  • 본 학습(medix-rl-data, 통합 모델에서 시작)은 후속 과제에서 수행함. K-BDS 계산 노드는 외부망이 없어서 외부 심판 API 를 호출할 수 없었음.

정보: RLVR 학습 스크립트(Slurm), 의료 복합 보상 함수와 의료 강화학습 스크립트, LLM 심판 시험 스크립트, 데이터 전처리 스크립트, 형식 붕괴 감시 도구, 전문가 병합 스크립트, 평가 스크립트(holdout · 글로벌 벤치마크)
등록: 마켓플레이스 등록(위 패키지에 포함), GitHub 저장소 공개		 Python 3.12, PyTorch 2.10(CUDA 12.9), ms-swift 4.1.3, vLLM 0.19.1 연동 스크립트, DeepSpeed 설정 파일, Slurm + 컨테이너 실행 스크립트

※ 계획서 대비 변경: 분산 학습 방식을 DeepSpeed ZeRO-3 에서 LoRA 데이터 병렬 학습(ms-swift, vLLM 연동)으로 바꿈. 의료 개방형 강화학습의 본 학습은 후속 과제로 넘김. 통합 모델 가중치는 비공개로 기탁함.
