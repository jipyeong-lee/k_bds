2. Stage-1 · 콜드스타트 SFT

2.1 목적

  • base 모델은 추론을 길게 쓴다(3.5~4.6K 토큰). 출력이 잘려 답에 닿지 못한다(파일럿 77% 잘림).
  • 답이 없으면 보상이 0 이다. 보상이 0 이면 RL 은 학습하지 못한다.
  • 콜드스타트 SFT 는 짧은 추론과 <think>/<answer> 형식을 가르친다.

3. Stage-2A · GRPO 변형 비교

3.1 목적

기본 GRPO 는 학습 정확도 0.50 에서 정체했다(job 57249). 원인은 학습 신호가 0 인 그룹(모든 응답이 다 맞거나 다 틀림)의 비율 증가다(0.24 → 0.33). 이 실험은 정체를 넘는 변형을 고른다.

7. Stage-2E · 전문가 통합

7.1 판정 기준 (실행 전에 정함)

  1. 각 도메인에서 전문가 성능의 90% 이상을 지킨다.
  2. 글로벌 벤치에서 SFT 모델보다 높다.
  3. 두 기준을 통과한 후보 중 (holdout + 글로벌)/2 가 높은 2개를 전체셋으로 평가한다.

  • 기탁 패키지의 merge.sh 로 공개 Qwen3.5-9B 에서 ta_w07 을 다시 만들었다. bf16 텐서 712개가 평가 모델과 비트 단위로 같다(job 83057).

9. 한계

  • 학습↔롤아웃 불일치가 커지는 근본 원인을 확인하지 않았다.
  • pmcvqa 의 RL 효과가 작은 원인을 확인하지 않았다. 객관식 구조의 한계라는 가설이 있다.
  • deepvision 전문가는 B200 에서, 나머지 두 전문가는 KISTI 에서 학습했다. 배치와 num_generations 가 다르다(5.2).
  • Stage-1 v3 형식 점수(0.909)는 최대 출력 2,048 에서 쟀다. 통합 모델 형식 점수(0.997)는 8,192 에서 쟀다. 두 값은 조건이 다르다.
  • w = 0.6, 0.8 같은 중간 가중치와 DELLA 의 다른 인자는 시험하지 않았다.
