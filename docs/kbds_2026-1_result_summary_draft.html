K-BDS 분석 인프라 활용지원 프로그램(2026년 1차, Track III) · 초안 2026-10-22
연구 제목
(Title)		의료 및 바이오 도메인 특화 멀티 모달 교차 추론 인공지능 모델 개발
(Development of a Multimodal Cross-Domain Reasoning Model Specialized for Medical and Bio Domains)
연구 책임자이현훈
책임자 소속서울대학교병원 · 융합의학교수
연구 목적
  • 멀티 모달 대형 언어 모델(Qwen3.5-9B 기반)에 강화학습을 적용하여 시각 인지와 단계적 추론 능력을 높임.
  • 범용 멀티모달 추론 데이터(DeepVision-103K)와 의료 멀티모달 데이터로 학습하여, 의료 글로벌 벤치마크(MedXpertQA-MM, MMMU-H&M)에서 SFT 모델 대비 성능 향상을 정량 입증함.
  • K-BDS 8gpu(A100 80GB) 노드에서 재현 가능한 강화학습 파이프라인(데이터 전처리 → SFT → RLVR → 전문가 통합 → 평가)을 구축하고 공개함.
시스템
활용 효과
  • 대형 모델 강화학습의 실행 가능성 확보: GRPO 는 정책 모델, 참조 모델, vLLM 롤아웃 엔진을 동시에 메모리에 올림. A100 40GB 단일 GPU 에서는 메모리 부족(OOM)으로 학습이 불가능함을 실측함. K-BDS 8gpu(A100 80GB × 8) 노드에서 9B 모델 GRPO 학습을 수행함.
  • 장기 학습의 안정적 수행: 8gpu 노드에서 GRPO 1 step 은 약 213초임(실측). 체크포인트 재개 체인으로 도메인 전문가 1 epoch(pmcvqa, 4,896 step)을 완주함. GRPO 변형 5종 비교와 혼합 데이터 확장 실행도 같은 노드에서 수행함.
  • 대용량 데이터 상주: 원본·전처리 데이터 약 305GB 를 K-BDS 스토리지에 두고 반복 실험(전문가 3종 학습, 체크포인트별 평가)을 수행함. 외부 반출 없이 데이터를 재사용함.
  • 사용 자원: 총 5,070.1 노드시간 사용(할당 5,000 노드시간 대비 101.4%)
연구 내용
및 결과
1. 데이터 구축 및 등록
  • 범용 멀티모달 추론 데이터 DeepVision-103K(10.3만 건, 10GB) 및 의료 멀티모달 데이터 medix-rl-data(5.1만 건, 24GB)를 K-BDS 에 등록함(등록번호 10.23220/KBDSC_20260306133407_2096, 10.23220/KBDSC_20260306133400_2097).
  • 강화학습용으로 도메인을 3개로 나눔: 시각 추론 deepvision 40,000건, 수학 추론 mmk12 15,204건, 의료 VQA pmcvqa 19,583건. 평가용 holdout 1,772건을 분리함.
2. 콜드스타트 SFT
  • <think>(추론)·<answer>(답) 형식을 학습시킨 SFT 모델을 만듦. 형식 준수율 0.185 → 0.909.
3. 도메인 전문가 강화학습(RLVR, GRPO)
  • 계획 변경: 세 도메인을 한 모델에 섞어 학습하면 약 900 step 에서 출력 형식이 무너짐(형식 붕괴). 그래서 DeepSeek-V4 구조(도메인 전문가 개별 학습 → 통합)로 바꿈.
  • 알고리즘: GRPO(dr_grpo 손실, gdpo 보상 정규화), LoRA(r=16), 정확도·형식·길이 복합 보상.

  • 세 전문가 모두 의료 글로벌 벤치마크(MedXpertQA-MM + MMMU-H&M, 3,712문항)에서 SFT 대비 향상함. 계획서 목표 3 을 충족함.
  • 범용 추론 학습(시각·수학)이 의료 벤치마크로 전이됨. 시각 추론 전문가가 MMMU-H&M 에서 62.27% → 77.57% 로 가장 크게 향상함.
4. 학습 붕괴 원인 분석
  • 장기 학습 시 형식 붕괴가 생김(mmk12 약 450 step, deepvision 3,428 step). 붕괴 응답의 96% 이상이 추론 종료 태그 전에 응답을 끝냄.
  • 붕괴 전에 학습 엔진과 롤아웃 엔진(vLLM)의 확률 불일치가 먼저 커짐을 발견함(log-ppl 차이 0.04 → 0.82).
  • 통제 실험(동일 체크포인트, 보정 유무만 다름): 토큰 단위 중요도 보정(TIS)은 붕괴를 약 20 step 늦추고 붕괴 폭을 줄이나 막지는 못함. 붕괴 직전 체크포인트를 전문가로 선택하는 기준을 세움.
5. 전문가 통합(모델 가중치 병합)
  • 세 전문가의 가중치 변화량(task vector)이 거의 직교함을 측정함(코사인 유사도 +0.01 ~ +0.11). 추가 학습 없는 산술 병합이 가능함을 확인함.
  • mergekit 기반 병합 후보 11종(Task Arithmetic, TIES, DARE, DELLA, Breadcrumbs, Model Stock, RAM 등)을 설계하고 10종을 비교함(DELLA 1종은 도구 오류로 제외).
  • 최종 통합 모델(Task Arithmetic, λ=0.7)을 K-BDS 에서 전체 holdout 1,772건으로 측정함. 정답률 63.32%(SFT 42.67% 대비 +20.65pp), 형식 준수율 99.7%. 각 전문가 대비 유지율: 시각 추론 95.3%(64.20/67.39), 수학 추론 107.8%(65.50/60.75), 의료 VQA 101.7%(59.00/58.0). 글로벌 벤치(3,712문항)는 56.22% 로 SFT 대비 +9.45pp 임(MedXpertQA-MM 37.80%, MMMU-H&M 77.75%). 단일 전문가 최고(시각 추론, 57.52%)보다 1.30pp 낮고 나머지 두 전문가보다 높음.
  • 결과: 세 도메인 능력을 하나로 합친 통합 모델 1종을 확보함(추론 비용은 단일 모델과 같음).
6. 의료 개방형 강화학습(복합 보상) 준비
  • 정확도·의미 일치·형식을 섞은 복합 보상 함수와 LLM 심판(LLM-as-a-judge) 루브릭을 구현하고 단위 시험(29/29)을 통과함.
  • 심판 모델 후보를 비교 평가하여 선정함. 학습 스모크 시험을 통과함.
  • 본 학습(medix-rl-data, 통합 모델 기반)은 후속 과제에서 수행함. K-BDS 계산 노드는 외부망이 없어 외부 심판 API 를 호출할 수 없었음.
