Stage-2 전문가 통합(모델 merging) 실험

기준 2026-10-22 14:00 · 작성 방식 ASD-STE100(한 문장에 한 사실, 능동문, 주의 사항을 먼저, 번호 절차) · 앞선 실험은 docs/experiments_2026-10.html

1. 요약

추가 학습 없이 전문가 3종을 합쳐 통합 모델 1개를 만들었다. 단순 가중 합산이 가장 좋았다.

  1. 전문가 3종을 확정했다: deepvision 2192, mmk12 350, pmcvqa 4896.
  2. 세 전문가는 모두 글로벌 의료 벤치에서 SFT 를 넘었다. 최고는 deepvision 2192 의 57.52%(SFT 46.77%)다.
  3. 세 전문가의 가중치 변화량(task vector)은 거의 직교한다. 코사인 유사도는 +0.01 ~ +0.11 이다.
  4. 선별 1위는 task arithmetic, 가중치 0.7(ta_w07)이다. 세 도메인에서 전문가 성능의 97~109% 를 지켰다.
  5. 부호 충돌을 다루는 기법(TIES 등)은 단순 합산보다 낫지 않았다.
  6. 상위 2개의 본평가(전체 평가셋)는 예약되어 있다. 결과는 19~20시에 나온다.
용어뜻
task vector (τ)전문가 가중치 − SFT 가중치. LoRA 에서는 ΔW = B·A·(α/r).
task arithmeticW = WSFT + Σ wᵢ·τᵢ. 가중치 wᵢ 로 합산한다.
보존율통합 모델의 도메인 정확도 ÷ 그 도메인 전문가의 정확도.
선별 / 본평가선별 = 축소셋(holdout 600 + 글로벌 600). 본평가 = 전체셋(holdout 1,772 + 글로벌 3,712).

3. 설계

3.1 질문과 판정 기준

질문: 추가 학습 없이 세 전문가를 한 모델로 합칠 수 있는가? 판정 기준은 실행 전에 정했다(docs/stage2_design.html §8).

  1. 각 도메인에서 전문가 성능의 90% 이상을 지킨다.
  2. 글로벌 벤치에서 SFT 보다 높다.
  3. 두 기준을 통과한 후보 중 (holdout + 글로벌)/2 가 높은 순서로 2개를 본평가한다.

4. 진단: task vector 코사인 유사도

세 도메인의 τ 는 거의 직교한다. 그러므로 합산해도 서로 간섭이 작을 것으로 예측했다.

  • 계산법: ΔW 를 만들지 않고 r×r 연산으로 정확히 구한다. ⟨B₁A₁, B₂A₂⟩ = Σ (B₁ᵀB₂) ∘ (A₁A₂ᵀ).
  • τ 의 크기(‖ΔW‖): deepvision 1.24, pmcvqa 1.21, mmk12 0.73.

해석. τ 가 거의 직교하므로 부호 충돌을 정리할 일이 적다. 그래서 TIES·DARE·RAM 이 단순 합산보다 낫지 않았다. 2~8위의 점수 차이(2pp)는 노이즈 범위다. 가중치 1.0 보다 0.7 이 나았다. 세 τ 를 그대로 더하면 변화량이 과해지는 것으로 본다(추정). Model Stock 은 보간 비율을 작게 잡아 SFT 쪽으로 끌려갔다(추정).
주의. 선별은 도메인별 200문항이다. 1~2pp 차이는 노이즈 범위다. 순위는 본평가로 확정한다.
