# Stage-1 콜드스타트 — 명분 · 적합성 판단 · Ablation Study

작성 2026-07-08, ablation 완료 2026-07-09. 계기: 콜드스타트 모델의 HealthBench(0.224)가 base(0.229)보다 낮아 "Stage-1을 제껴야 하나?"라는 문제제기 → **콜드스타트 ablation study 로 순가치 확정**.

**결론 한 줄**: 콜드스타트는 **Stage-2 RL의 전제조건**. 없으면 base→RL은 형식 미학습(FormatThink 0)·잘림·홀드아웃 0.18(콜드스타트 SFT 단독 0.22에도 미달). → [§3 Ablation Study](#3-콜드스타트-ablation-study).

---

## 1. 명분 — 콜드스타트는 왜 필요한가

**단일 논리: RL은 0이 아닌 보상이 있어야 학습한다.**

```
base: 장황 추론(3.5~4.6K토큰, HealthBench서 최대 44K자 확인)
  → max_completion 에서 잘림
  → <answer> 미도달 → 정확도·형식 보상 = 0
  → advantage gradient = 0 → RL 이 오를 언덕이 없음   ← 파일럿 실패(77% 잘림, Format=0)
```

콜드스타트 = 이 순환을 깨는 **인에이블러(enabler)**. "정확도 부스터"가 아니라 **"RL을 학습 가능 상태로 만드는 전제조건"**.

### 명분의 증거 (측정됨)

| 지표 | base | 콜드스타트(RL 0%) | 효과 |
|---|---|---|---|
| **DeepVision 홀드아웃 Acc** | 0.15 | 0.22 | **+47%** |
| 후속 GRPO FormatThink | 0.05 | 0.27 | **5배** |
| 답 잘림(파일럿) | 77% | 해소 | RL 인에이블 |
| 이후 Stage-2 결과 | — | plateau 돌파(dr_grpo Acc 0.526), 홀드아웃 0.38 | — |

→ **자기 타깃(DeepVision·RL 인에이블)에서 명확히 작동.** 그 위에서 Stage-2 성공.

### HealthBench는 콜드스타트의 판단 기준이 아님
- HealthBench = **텍스트 의료 QA**. 콜드스타트 = **DeepVision 시각추론 RL 인에이블 + 형식 정렬**. **오프타깃**.
- base 0.229 vs 콜드스타트 0.224 = **−0.005, 노이즈 내 동률**(회귀 아님). 형식 정렬이 텍스트 의료 지식을 늘리지 않으니 불변이 정상.
- 콜드스타트가 실제로 바꾼 것: **instruction_following +0.044**, 출력 간결화(평균 8.9K자, judge 파싱실패 9.9%→5.0%) — 프로파일 이동.

## 2. 실제 돌린 Stage-1 은 적합했나 (비판적 판단)

**실제 구성**: RFT 거절샘플링 727건 · 4 epoch · LoRA r16/a32 · val loss epoch1 수렴(0.214)·token_acc 0.924.

### 적합한 점
1. **목적 달성 증명** — 형식 주입 → RL 인에이블 → Stage-2 plateau 돌파. 다운스트림 성공이 최종 검증.
2. **in-domain 자기증류** — 1차 clevr_math(쉬움) 일반화 실패 → DeepVision 자기 롤아웃으로 교체한 판단이 옳음.
3. **과적합 없음** — val 평탄, token_acc 0.924 유지.

### 미흡·위험한 점 (정직하게)
1. **4 epoch 과다** — val 이 epoch 1 에 이미 수렴(0.2149→0.2138 평탄). 1~2 epoch 충분. 낭비(다만 ~5분이라 손실 미미).
2. **"가장 짧은 정답" 선별 → 쉬운 문제 편향 가능성** — 필터가 `정답 AND 간결`이라 **모델이 이미 잘 푸는(쉬운) 문제**에 쏠릴 수 있음. 어려운 문제의 간결화 전이는 **가정**(간접 증거만: FormatThink 5x·홀드아웃 +47%).
3. **727건·DeepVision 전용** — 규모 작고 도메인 단일. **Stage-3(의료 medix) 형식 전이 미검증**(시스템프롬프트 동일이라 형식은 옮겨가되, math 기반 "간결 추론"이 개방형 의료에 맞는지는 Stage-3서 관찰 필요).
4. **순가치 clean ablation 부재** — "base→Stage-2(콜드스타트 없이)"를 홀드아웃 수정 후 비교한 적 없음(파일럿 증거는 정비 이전). → **본 ablation 으로 해소 예정**.

### 종합 판단
> **적합하다 — 단 "최소 기능(minimum viable) 콜드스타트"로서 적합**하며, 최적은 아니다.
- 명분(RL 인에이블) **달성·입증** → **제끼면 안 됨**(파일럿 실패 재현 위험).
- 효율(epoch)·선별편향·Stage-3 전이엔 개선 여지 명확.

## 3. 콜드스타트 Ablation Study

### 3.1 가설
> **H1**: Stage-1 콜드스타트는 Stage-2 RL의 **전제조건(enabler)**이다 — 없으면 base의 장황→잘림→형식0 때문에 RL이 형식·간결을 못 배운다.
> **H0(귀무)**: 콜드스타트 없이도 RL이 스스로 형식을 배워 유사 성능에 도달한다(콜드스타트는 가속 역할일 뿐).

### 3.2 실험 설계
**절제 변수(ablated) = 콜드스타트 init 유무.** 나머지(데이터 trainonly · loss_type dr_grpo · LoRA r16/a32 · 보상 · 하이퍼파라미터)는 **전부 통제**. `21_rlvr_grpo_adv.slurm` 에서 `INIT_MODEL` 만 교체.
- **처리군(treatment)**: `INIT_MODEL=base(raw Qwen3.5-9B)` → dr_grpo & GDPO 2-arm, MAX_STEPS=200 (`job 59946`/`59970`).
- **대조군(control)**: 기존 `INIT_MODEL=콜드스타트` 경로(이미 측정: RL0% 0.22, step600 0.38).
- **측정**: ① training dynamics(FormatThink·clip·AccMix) ② checkpoint-200 병합 → DeepVision 층화 홀드아웃 N=200 (`47_eval_ablation.slurm`).

### 3.3 조건 — 2×2 요인 설계 (콜드스타트 × RL)

DeepVision 홀드아웃 Acc 로 본 2×2 (2026-07-09):

| | **RL 無** | **RL 有** | RL 효과 |
|---|---|---|---|
| **콜드스타트 無** | base **0.15** | base→dr_grpo(step200) **0.18** | +0.03 (미미) |
| **콜드스타트 有** | 콜드스타트 **0.22** | 콜드스타트+dr_grpo(step600) **0.38** | **+0.16** |
| **콜드스타트 효과** | **+0.07** | **+0.20** | — |

→ **강한 상호작용(interaction)**: RL은 **콜드스타트가 있어야만** 크게 작동(+0.16 vs +0.03). 콜드스타트 자체도 main effect(+0.07)를 가짐.

### 3.4 결과 상세

**① training dynamics (step 1~100 구간평균)** — 콜드스타트 없이 RL 하면 형식이 안 붙음:

| arm | FormatThink(1-25→76-100) | clip | AccMix | 대조(콜드스타트 init GRPO) |
|---|---|---|---|---|
| base→dr_grpo | 0.001 → 0.004 | 0.54→0.43 | 0.42→0.48 | Format **~0.26 시작** |
| base→GDPO | 0.002 → 0.002 | 0.46→0.41 | 0.47→0.46 | (동일) |

**② 홀드아웃 (checkpoint-200, N=200)**:

| 모델 | Acc | math | vl | 형식 |
|---|---|---|---|---|
| base→dr_grpo (콜드스타트 無) | **0.18** | 0.137 | 0.219 | 0.205 |
| base→GDPO (콜드스타트 無) | *채점 중* | | | |
| *(참조) 콜드스타트 RL0%* | 0.22 | — | — | 0.32 |
| *(참조) 콜드스타트+dr_grpo step600* | 0.38 | 0.358 | 0.400 | 0.425 |

### 3.5 결론 — **H0 기각, H1 채택 (콜드스타트 필수)**
1. **FormatThink 100스텝 내내 ~0 정체** — base→RL은 형식을 못 배움(콜드스타트는 0.26 시작). 회복 없음. **GDPO도 동일** — 보상별 정규화가 0 신호를 못 살림.
2. **clip ~0.4 지속 + 학습 2~3배 저속** — 잘림이 형식뿐 아니라 속도까지 저해(매번 6144토큰 생성).
3. **홀드아웃 0.18 < 콜드스타트 RL0% 0.22** — **200스텝 RL이 콜드스타트 SFT 한 번보다 못함**. 콜드스타트+RL(0.38)과는 2배 격차.
4. AccMix 소폭 상승(0.42→0.48)은 관대 파서가 형식 없이 답만 잡은 것 — 형식·간결 학습은 실패.
5. 2×2의 강한 상호작용이 H1의 정량 근거: **RL 이득은 콜드스타트에 조건부**.

→ **"우리 계획 목적(형식 일관 + DeepVision 시각추론 RL)에는 Stage-1 콜드스타트가 필요"** 명분 확정.

---

## 4. 결론·권고

- **✅ Stage-1 콜드스타트는 필수** — ablation으로 확정. 콜드스타트 없이 base→RL 200스텝은 홀드아웃 0.18(콜드스타트 SFT 단독 0.22에도 못 미침)·Format 0 정체·잘림·저속. **제끼면 안 됨**.
- **HealthBench 동률(0.229 vs 0.224)은 콜드스타트 무용의 근거가 아님** — 오프타깃(텍스트 의료) 지표일 뿐. 콜드스타트의 타깃(DeepVision·RL 인에이블)에선 명확히 필요.
- **현행 유지 + Stage-3 진행**. 향후 콜드스타트 재학습 시 개선안: **epoch 1~2**(과다 교정) + 어려운 문제 비중 상향 + (Stage-3 대비) medix 형식 소량 혼합 검토.
